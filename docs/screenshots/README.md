# 截圖規格與拍攝指引

本目錄存放 [根目錄 README](../../README.md) 「視覺展示」章節所需的應用截圖。

## 如何啟用截圖

1. 依下表拍攝 6 張截圖，以指定檔名存入本目錄
2. 開啟 `README.md`，找到「### 應用截圖」下方的 HTML 註解區塊（`<!-- ... -->`）
3. 移除註解符號 `<!--` 與 `-->`，並刪除上方「截圖尚未補齊」的提示段落

## 所需截圖

| 檔名 | 頁面 | 路徑 | 拍攝重點 |
|------|------|------|---------|
| `home.png` | 首頁 — 商品瀏覽 | `/` | 輸入搜尋關鍵字並切換排序，讓搜尋框、排序下拉與商品卡片網格同時入鏡 |
| `product.png` | 商品詳情 | `/products/1` | 商品大圖、價格、數量選擇與「加入購物車」按鈕 |
| `cart.png` | 購物車 | `/cart` | 至少 2 項商品，呈現數量調整、小計與總金額 |
| `checkout.png` | Stripe 結帳 | `/checkout` | Stripe 分離式卡片欄位（卡號／到期日／CVC），可填入測試卡號 `4242 4242 4242 4242` |
| `orders.png` | 我的訂單 | `/orders` | 訂單列表含訂單狀態與付款狀態欄位 |
| `admin.png` | 管理後台 — 訂單管理 | `/admin/orderManage` | 待確認訂單表格與「確認／取消」操作按鈕（需以 `admin@gmail.com` 登入） |

## 規格建議

| 項目 | 建議值 |
|------|--------|
| 格式 | PNG |
| 解析度 | 1440 × 900（或等比例 16:10） |
| 瀏覽器視窗 | 寬度 1440px，隱藏書籤列與開發者工具 |
| 主題 | 統一使用淺色模式（可另外補一張深色模式截圖展示該功能） |
| 檔案大小 | 單張建議 < 500 KB，必要時以 TinyPNG 等工具壓縮 |

## 拍攝前準備

```bash
# 1. 啟動後端（自動植入 30 筆商品種子資料）
cd backend && ./mvnw spring-boot:run

# 2. 啟動前端
cd frontend && npm install && npm run dev
```

以 `admin@gmail.com` / `1234` 登入後，先建立一筆測試訂單，`orders.png` 與 `admin.png` 才會有內容可拍。

## 隱私注意事項

截圖前請確認畫面中不含真實個人資料：使用種子帳號與 Stripe 測試卡號即可，勿使用真實 email、手機號碼或信用卡資訊。
